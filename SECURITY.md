# Security and responsible reporting

Grid is currently a prerelease local desktop app. The trusted-host mode runs
project code with your account's permissions. It is unsuitable for untrusted
repositories or a public hosted service. See [SAFETY.md](SAFETY.md).

Do not put credentials, exploit details or private project contents in public
issues. Use [GitHub private vulnerability reporting](https://github.com/SilkForgeAi/grid-ai/security/advisories/new)
on the public repository. Private reporting has been enabled and verified.

Include the version, platform, affected component, a minimal benign reproduction,
expected/actual behavior and any known impact. Do not test against other users'
machines or real third-party accounts. No response-time or bounty commitment is
currently made.
