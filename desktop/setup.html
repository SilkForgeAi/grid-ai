Set up Grid

Grid installs its own engine. If that didn't work (no internet, or it was interrupted), try it again:

Or use an engine you installed yourself:

In the list, find Grid and turn on the folder. If Grid isn't listed, use Full Disk Access instead and add Grid from Applications.

The Grid app runs Grid's engine: the grid program in Grid's Python environment. Only if you have never set it up, run this once in Terminal:

cd ~/Desktop/"Grid AI"/grid-ai && uv venv -p 3.12 .venv && uv pip install -e .

Then click Try again. If it lives somewhere else, choose the grid program yourself (inside .venv/bin).
