# Commit messages

Format: `type(scope): summary` in the imperative, at most 72 characters, then a blank line and a body explaining *why*.
Types: feat, fix, refactor, test, docs, chore, perf, build, ci.
Mention breaking changes in a `BREAKING CHANGE:` footer.
