## Download status

Public downloads are being prepared. **There are no supported public builds yet.**
macOS and Windows are planned; neither is currently advertised as ready to install.
Signed, tested builds will appear on the Releases page when release checks clear.

This repository hosts public download information and support. Grid is proprietary;
its application source and development history are not published here. GitHub's
automatic source archives contain only this repository's public documents.

## Before using Grid

Grid runs coding tasks using a model provider you configure. Provider charges and
data handling depend on your provider. Review changes before using generated work.
Keep backups and keep credentials out of project files.

Local safeguards cannot guarantee that every harmful request is detected.
The current development build includes a trusted-host mode with your account's
permissions and an optional container mode requiring additional setup. Public
installation instructions and supported safety settings will accompany each build.
