## A place to experiment

Start with a small project, ask for a hint, and try one change at a time.
Play, Code, and Understand modes connect running a project with reading its code
and learning from your guide. The Start here guide helps beginners find their way.
Particle Lab adds a space to explore motion, shape, and color.

## Public downloads, private development

This repository contains public documentation and support information only.
Grid's application source, build scripts, and private development history are
not committed here. GitHub's automatic source archives contain these public
documents, not the application's development checkout.

Public release packages must exclude the developer's API keys, credentials,
saved model profiles, local model weights, projects, conversations, and logs.
Each user will configure their own model provider and credentials. A local model
requires the user's own installation and setup. Provider charges and data
handling depend on the provider they choose.

Desktop applications can be inspected and reverse engineered. A documents-only
repository does not make the contents of an application download secret.

## Before using Grid

Review generated changes and verification results, keep backups, and keep secrets
out of project files. Safeguards reduce risk; they cannot guarantee that every
harmful request is detected or that every generated program is safe.

The current development build includes trusted-host execution with the user's
account permissions and an optional container mode requiring additional setup.
Public installation instructions will explain the supported execution settings.
