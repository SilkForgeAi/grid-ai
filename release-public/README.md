# Grid

**Learn to code. Have fun building.**

Grid is open source under MIT. Explore the source, setup instructions, beginner
workflow, and contribution guide in the [main repository](https://github.com/SilkForgeAi/grid-ai).
Each user supplies their own model and credentials. Publisher credentials, saved
profiles, conversations and model weights are not included.

There are no supported public installers yet. macOS development builds and planned
Windows support are described in the repository. Third-party dependencies retain
their own licenses; source publication does not clear app distribution requirements.
